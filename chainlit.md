# 💳 Interchange AI POC - Assistente de Taxas

Bem-vindo ao assistente inteligente para análise de taxas de intercâmbio das bandeiras Visa e Mastercard.

Este ambiente permite:
- **Consultar Regras:** Faça perguntas sobre taxas de intercâmbio em linguagem natural.
- **Análise Documental:** O sistema busca trechos dos manuais originais para fundamentar as respostas.
- **Simulação:** Em breve, suporte para simular transações diretamente via chat.

### Como usar:
1. Digite sua dúvida sobre taxas (ex: "Qual a taxa de crédito para e-commerce na Visa?").
2. O sistema buscará as evidências nos documentos carregados e gerará uma resposta explicativa.
3. Clique em **BACKSTAGE** na resposta para ver os trechos técnicos recuperados.

---
*Este projeto utiliza processamento local (Llama-cpp) para garantir a privacidade dos dados.*
